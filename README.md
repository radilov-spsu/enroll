# Регистрация на курс

Чтобы получить **личный приватный репозиторий** для сдачи работ, заполните форму —
это одна страница и четыре поля.

### 👉 [Заполнить заявку](https://github.com/radilov-spsu/enroll/issues/new?template=enrollment.yml)

Нужен только аккаунт на GitHub. Ничего устанавливать и клонировать не надо.

---

## Как это работает

1. Нажимаете ссылку выше, входите в свой аккаунт GitHub.
2. Заполняете форму: фамилия, имя, отчество, группа, отмечаете курсы.
   ФИО — **кириллицей, как в зачётке**.
3. Нажимаете **Create**. Через минуту робот ответит комментарием:
   всё ли в порядке и как будет называться ваш репозиторий.
4. Преподаватель проверяет заявку и подтверждает её.
5. В заявке появляется ссылка на ваш репозиторий, а на почту — приглашение.

Репозиторий приватный: его видите только вы и преподаватель. Один репозиторий
выдаётся на все предметы, внутри — папка на каждый курс.

## Если робот нашёл ошибку

Он напишет, что именно не так. Откройте свою заявку, нажмите **⋯ → Edit**
в правом верхнем углу первого сообщения, поправьте поля и сохраните —
проверка запустится заново автоматически. **Новую заявку создавать не нужно.**

## После подтверждения

1. **Примите приглашение.** Письмо придёт на почту, привязанную к GitHub,
   либо откройте ссылку на репозиторий и нажмите **Accept invitation**.
   Без этого доступа не будет.
2. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/radilov-spsu/ваш-репозиторий.git
   ```
3. Откройте `README.md` внутри — там структура папок и правила сдачи работ.
   Работы сдаются через Pull Request внутри вашего репозитория; как это
   делается, подробно расписано там же.

Материалы курсов лежат в публичном репозитории
[**materials**](https://github.com/radilov-spsu/materials).

## Частые вопросы

**Как будет называться мой репозиторий?**
`фамилия-имя-отчество-год` транслитом. Иванов Иван Иванович →
`ivanov-ivan-ivanovich-2026`. Год — учебный, чтобы работы разных лет
не смешивались.

**У меня нет отчества.**
Оставьте поле пустым, оно необязательное.

**Я ошибся в ФИО, а заявку уже подтвердили.**
Напишите комментарий в свою заявку — преподаватель переименует репозиторий,
это делается в одно действие и ничего не ломает.

**Я отметил не те курсы.**
Если заявку ещё не подтвердили — отредактируйте её. Если уже подтвердили —
ничего страшного: недостающую папку курса можно создать самому, это просто папка.

**Заявку подтвердили, но приглашения нет.**
Проверьте спам и https://github.com/notifications. Ссылку на репозиторий можно
открыть напрямую — баннер с кнопкой **Accept invitation** будет наверху страницы.

**Робот молчит больше нескольких минут.**
Скорее всего заявка создана без формы (пустым issue). Закройте её и заполните
[форму](https://github.com/radilov-spsu/enroll/issues/new?template=enrollment.yml).

**Можно ли записаться на второй курс позже?**
Да, репозиторий один на все предметы — напишите преподавателю, папка добавится.

**Ничего не получается.**
Напишите комментарий в свою заявку. Это первая задача курса, а не экзамен.
